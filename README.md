## AVAILABLE TIMES

The backend of this project is ran locally as ec2 instances with gpus are very expensive costing atleast 1.5$ an hour. To avoid this I am hosting the backend locally using ngrok to access it from the frontend.
This means that this website's generator will only be available during the times that this computer is on. Typically around 10 - 9. Generated and saved files can still be accessed as those are stored using firebase storage and firetstore.
